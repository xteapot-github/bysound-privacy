Bysound Privacy Policy

Bysound is an on-device keyboard application. The current build processes typed tokens and candidate ranking locally on the device to provide tap suggestions.

What the app processes

  • Characters typed into supported text fields
  • Candidate ranking data derived from bundled English and Thai lexicon assets

Data handling

  • The shipped app does not include a feature that uploads typed text to a remote server.
  • The shipped app does not include account creation or cloud sync.
  • Lexicon assets are bundled inside the app package and loaded locally.

Diagnostics and future changes

  • If crash reporting, analytics, or remote suggestion services are added later, this policy and the Play Data Safety answers will be updated before release.
  • Release builds document any third-party SDKs that process user or device data.
